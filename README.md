# HR Analytics Dashboard Using Power BI
## Overview
This project focuses on the development of an HR Analytics Dashboard using Power BI to analyze employee attrition. The dashboard was designed to provide actionable insights into retention trends, turnover rates, and key HR metrics to aid in data-driven decision-making for improving employee retention strategies and optimizing workforce management.

## Features
Employee Attrition Analysis: Visualizes employee attrition patterns, identifying key factors that influence turnover such as age, gender, department, job role, salary, and years at the company.
Key Metrics and KPIs: The dashboard displays essential metrics such as:
Attrition Rate
Average Employee Tenure
Turnover by Department/Job Role
Salary Range and Attrition Correlation
Attrition Trends by Education, Age, and Gender
Filters and Slicers: Allows users to filter data by multiple dimensions including department, gender, age, job role, salary, and years at the company.
Dynamic Visuals: Interactive bar charts, pie charts, and line graphs to visualize trends and patterns, helping HR professionals make informed decisions about workforce management.
## Data Insights
Attrition Trends: The dashboard highlights trends in employee attrition over time and the departments with the highest turnover rates.
Key Demographics: Provides insights on attrition based on demographic factors like age, education, and gender.
Retention Drivers: Analyzes and visualizes how salary, job role, and years at the company influence employee retention.
## Technologies Used
Power BI: Used for data modeling, visualization, and dashboard creation.
Data Filtering & Analysis: In-depth filtering and aggregation techniques to extract meaningful insights.
## Usage
Load Data: Import employee data that includes attributes such as employee ID, department, job role, age, gender, salary, and attrition status.
Customize Filters: Use slicers to filter data by specific parameters like department, tenure, and gender.
Explore Insights: View the visualizations to analyze trends and identify factors contributing to attrition.
## Conclusion
This HR Analytics Dashboard provides a comprehensive tool for HR teams to monitor, analyze, and understand employee turnover patterns. By leveraging this dashboard, HR professionals can make data-driven decisions to improve employee retention and foster a positive work environment.
